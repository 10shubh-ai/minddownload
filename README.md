# MindDownload website

Landing page for **MindDownload**, the native macOS download manager. It features 32 parallel connections, YouTube up to 4K, Reels to MP3, browser capture and pause & resume, all local-only.

- Live site: https://10shubh-ai.github.io/minddownload/
- Download: [latest release](https://github.com/10shubh-ai/minddownload/releases/latest)

This is a static site (`index.html`, `style.css`, `main.js`) with no build step. Run it locally with `python3 -m http.server`.
